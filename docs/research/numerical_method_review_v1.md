# Uranium column: numerical-method review v1

This review examines the time integration declared in docs/specs/URANIUM_REDOX_TRANSPORT_PREREG_v1.md (frozen at b10e7b4, sha256 5370767fa8e64a607f7e169901f05d1ac1514ad699ce4721c2e39444591002e4) before any solver code exists. It is a review record, not a specification. Its recommendation is carried out by Amendment A1 (docs/specs/URANIUM_REDOX_TRANSPORT_PREREG_v1_AMENDMENT_A1.md), which supplements v1 without editing it. Every number below comes from a short arithmetic script, scripts/uranium_a1_arithmetic.py, except those taken from Østerby and those marked as estimates. The script builds the Crank-Nicolson matrices that v1's discretization defines and inspects their entries. It never time-steps the model or looks at a solution. Its output is receipts/uranium_a1_arithmetic_2026-10-18.txt.

Two sources were read in full. Ole Østerby, "Five ways of reducing the Crank-Nicolson oscillations" from the copy on an Imperial College course page. The copy carries no venue details; a catalogue record lists it as DAIMI Report Series 31(558), 2002, and a later citation gives BIT Numerical Mathematics 43 (2003) 811 to 822. Dagmar Žáková and Peter Frolkovič, "Compact implicit high-resolution numerical scheme for multicomponent transport problems with Langmuir sorption" (arXiv:2609.08320, 2026), through alphaXiv. Luskin and Rannacher's analysis of implicit starting steps for Crank-Nicolson is known by name only and is not cited for any content. The coverage limits of the evidence review (no Consensus, no SciSpace in this session) apply here too.

Hunter's reviewer raised the central issue, and it holds. v1 sets Δt = 0.5 R Δx / v. The diffusion number is d = D_eff Δt / (R Δx²), so d = 1/(2 Pe_cell), where Pe_cell = v Δx / D_eff. The v1 grid rule bounds Pe_cell above by 2, which bounds d below by 1/4, but nothing bounds d above. R cancels from d, from the step counts and from every sign condition below, so one row covers all four K_d values.

The growth factor explains why this matters. For Crank-Nicolson on the diffusion equation, Østerby's equation (5) gives g(φ) = (1 - 2d sin²(φ/2)) / (1 + 2d sin²(φ/2)), so the highest-frequency factor is (1 - 2d)/(1 + 2d). It equals 0 at d = 0.5 and approaches -1 as d grows; his Table 1 lists -0.9048 at d = 10 (page 3). He also notes (page 2) that Crank-Nicolson tends to oscillate when there is a jump "in the initial condition or between the initial condition and a boundary condition", with oscillations that are weakly damped and may persist. The v1 column starts with exactly that jump: C = 0 in the column and C = C0 at the inlet from t = 0. At v1's d = 20 the highest-frequency factor is -0.951, so that component flips sign every step and loses about 5 percent per step. In B1, d doubles with each refinement, because Δt shrinks only in proportion to Δx. Østerby's remedies either change the first step (one or two implicit steps, a small first step, Pearson substeps, or exponentially growing substeps) or average the output. v1 adopts none of them, and the recommendation below does not either.

Three further problems surfaced while checking this, all present in v1 as frozen. First, control C2(b) declares a corrupted variant detected when "S is negative anywhere". That rule can tell the corrupted model from the correct one only if the correct scheme provably keeps S ≥ 0. Under v1's step rule that is not guaranteed. Once the explicit half of a Crank-Nicolson step has a negative diagonal (d > 1 in the interior), the sufficient condition for non-negativity fails and negative concentrations are possible, and S accumulates θ k_red C. No run was made to show them. C2 also says "in a run with k_red = 1e-10 1/s" without naming the run. Second, v1 does not say how output times are reached. One tenth of a travel time is 0.2 N steps of 0.5 R Δx / v, which is 12.8 steps at N = 64 and 16.2 at N = 81. Third, the grid rule N = max(64, ceil(Pe_s / 2)) lands exactly on Pe_cell = 2 for six of the nine (v, D) pairs, where the downstream coefficient D_eff/Δx - v/2 is zero in exact arithmetic. In f64 the nominal Pe_s of 160 evaluates to 160.00000000000003 for one pair and 160.0 for another, giving N = 81 or N = 80; the same happens at 1600 (N = 801 or 800), and at 16000 the single pair rounds up to N = 8001. The script found that coefficient to be exactly 0.0 or positive in every case, but an implementation that evaluates it in a different order could produce a value of either sign at the rounding level. Sign checks therefore need a small floating-point allowance, and the order of operations for Pe_s should be pinned.

A step bound derived from the scheme itself removes the first problem and the main one together. Write v1's semi-discrete system as R dC/dt = A C + b, using v1's face rules exactly. In an interior cell the central advective terms cancel on the diagonal, so |A_ii| = 2D/Δx² + k χ_i. In the inlet cell the half-cell diffusive difference and the inlet advective face give |A_11| = 3D/Δx² + v/(2Δx) + k χ_1. In the outlet cell the zero-gradient face gives |A_NN| = D/Δx² + v/(2Δx) + k χ_N. Each off-diagonal entry is (D/Δx ± v/2)/Δx, which is non-negative when Pe_cell ≤ 2. A Crank-Nicolson step solves M C^(n+1) = E C^n + Δt b, with M = R I - (Δt/2) A and E = R I + (Δt/2) A. If Δt ≤ R / max_i |A_ii|, every diagonal entry of E is at least R/2, so E is entrywise non-negative. M has positive diagonal and non-positive off-diagonal entries. In every row |A_ii| is at least the sum of the off-diagonals (with equality in interior cells outside the organic zone and in the outlet cell), and adding R > 0 makes every row strictly diagonally dominant. M is therefore a nonsingular M-matrix, and its inverse is entrywise non-negative. The inlet source b_1 = (v/Δx + 2D/Δx²) C0 is non-negative. Hence C^n ≥ 0 implies C^(n+1) ≥ 0. Applying the same argument to W = C0 - C shows C ≤ C0: the constant vector C0 satisfies the scheme with a non-negative residual, Δt k χ_i C0 in each cell. S is advanced by adding θ k_red χ (C^n + C^(n+1)) Δt / (2 ρ_b), which is non-negative, so S never decreases. The factor of one half in the bound mirrors v1's Courant factor of 0.5. In an interior cell with pure diffusion it is the bound d ≤ 1/2, where every Crank-Nicolson growth factor in Østerby's equation (5) is non-negative. The bound is conservative, since E ≥ 0 needs only d ≤ 1 there, and because the inlet cell usually binds, the interior d actually used is near 1/3. Keeping v1's own bound alongside it, Δt_rule = min(0.5 R Δx / v, R / max_i |A_ii|), keeps Δt = O(Δx). The truncation-error argument in v1 section 3 then still gives an expected order of 2.

The script checked this numerically, for both B1 and production. For all 144 production runs (the record prints the 36 rows with K_d = 0; the loop checked all four K_d values) and the three B1 grids, under the amended rule with the landing rule of A1, every diagonal entry of E is at least R/2 and M is strictly diagonally dominant in every row. Under the amended rule, d in the interior is between 0.158 and 0.332 in production and between 0.320 and 0.330 in B1. The worst step count is 80,100, in the run with N = 8001, against v1's 80,010 for the same run. The largest increase is in the most diffusive pair, v = 1e-10 and D = 1e-9, from 640 steps to 38,600 on 64 cells. B1 needs 800, 3,137 and 12,417 steps where v1 needed 128, 256 and 512.

The step bound makes B1's spatial refinement nearly blind to temporal error. With d capped, Δt shrinks like Δx² in B1, and the temporal error is expected to become much smaller than the spatial one (order-of-magnitude estimates, not runs: (Δx/W)² ≈ 2e-3 spatial at N = 256, with W ≈ 5.7 m the front spread, against about 1e-5 temporal, below). So B1 no longer exercises the temporal accuracy that the reviewers asked about, and a separate pre-registered check is needed. The proposal is to repeat B1 at N = 256 with the A1 step and with half and a quarter of it (800, 1,600 and 3,200 steps), and to take the observed order from successive differences, which cancel the shared spatial error. The expected order is 2. As an order-of-magnitude estimate, not a run: with Δt = 2e7 s and a front-spreading time near √(2 D t*)/v ≈ 5.7e9 s, the relative temporal error is of order (Δt/T)² ≈ 1e-5, far above rounding.

Žáková and Frolkovič treat a different problem: advection only (their introduction explicitly sets diffusion and dispersion aside), with nonlinear Langmuir sorption. They control unphysical oscillations near steep fronts at large Courant numbers with WENO reconstruction and a time limiter that pulls the scheme locally toward first-order upwind (introduction, section 3.1 and section 4). Their work supports the general point that large steps near sharp fronts need explicit treatment. It does not validate this column, and its machinery is not adopted. v1 is linear, its fluxes are central with Pe_cell ≤ 2, and the bound above gives non-negativity directly.

Recommendation, carried out by Amendment A1:
- keep Crank-Nicolson and central fluxes;
- add the derived step bound and a constant step that lands on every output time;
- pin the f64 order of operations for Pe_s;
- add a non-negativity and boundedness check with a declared floating-point allowance;
- add the temporal-refinement check on B1;
- run C2 in all 36 configurations with k_red = 1e-10, and require the uncorrupted model never to trigger either detection rule.

No limiter, no Rannacher start, and no change to B1, B2, the ledger, C1, the sweep or any parameter.

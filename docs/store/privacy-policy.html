What the app does

Oklo Fixture Viewer presents six fields from the revision 0 Oklo fixture. Users can select a field, change the displayed phase, choose a pulse boundary, select a null scenario, and inspect plan, section, volume, and chart views. Displayed values come from prescribed fixture functions. Phase navigation does not run a physical dynamics model.

Data handled by the app

The reviewed application source does not define an account, analytics, advertising, or cloud sync feature. The source and direct dependencies reviewed for this draft do not define an app network client or a user-data permission. These are source-level findings only. Runtime network capture and installed-app review have not been completed, so this draft does not claim that the app collects or transmits no data.

Before publication, record whether any data is collected, shared, stored, or transmitted by the built applications or their dependencies. Update this policy and the store disclosures to match that evidence.

Device storage and permissions

The reviewed Android manifest does not request internet access or user data access. Its merged manifest includes one AndroidX-generated signature-only permission for non-exported dynamic receivers. The reviewed iOS project does not declare a data-access usage description. Runtime behavior remains to be checked.

Service providers and distribution platforms

The iOS app uses Apple platform frameworks and a local Rust core. The Android app uses AndroidX UI and lifecycle libraries, Kotlin coroutines, and the local Rust core through JNI. Neither app declares an analytics or advertising SDK directly. Complete the transitive dependency and runtime audit before publication.

Apple and Google may process information under their own terms when users obtain or update the app through their stores. The publisher must complete the applicable store privacy disclosures.

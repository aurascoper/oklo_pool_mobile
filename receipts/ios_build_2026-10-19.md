## Generated framework and app builds

The repository does not commit `OkloCoreFFI.xcframework`. In a clean worktree it must be generated first:

```sh
bash scripts/build_xcframework.sh
```

The script built all three Rust slices offline and created the framework. The app then built and tested cleanly:

```sh
xcodebuild -project ios/OkloPool.xcodeproj -scheme OkloPool \
  -destination 'generic/platform=iOS' CODE_SIGNING_ALLOWED=NO build

xcodebuild -project ios/OkloPool.xcodeproj -scheme OkloPool \
  -destination 'generic/platform=iOS Simulator' CODE_SIGNING_ALLOWED=NO build

xcodebuild test -project ios/OkloPool.xcodeproj -scheme OkloPool \
  -destination 'platform=iOS Simulator,id=646CF1C6-8720-4906-B73B-FD46ACAA8EF0'
```
